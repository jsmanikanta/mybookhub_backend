# MyBookHub Backend

The backend service for **MyBookHub**, an online marketplace designed for students to buy and sell books easily. This backend is built using Node.js, Express.js, and MongoDB, and handles authentication, book management, image uploads, and order-related operations.

## Features

- RESTful API architecture  
- JWT-based authentication (Login/Register)  
- Book listing and management  
- User profile management  
- Image upload support (Cloudinary integration)  
- Order handling system  
- Secure middleware for protected routes  
- Scalable backend structure  

Backend systems like this act as the core layer that connects frontend applications with databases and services, handling authentication and data flow. :contentReference[oaicite:0]{index=0}
